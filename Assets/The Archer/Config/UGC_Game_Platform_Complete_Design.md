## 二、游戏模板体系

### 2.1 支持的游戏模板

| 模板类型 | 模板ID | 核心玩法 | 典型代表 |
|----------|--------|----------|----------|
| **肉鸽 Roguelike** | `template_roguelike` | 随机关卡、能力成长、永久死亡 | 吸血鬼幸存者、弓箭传说 |
| **沙盒 Sandbox** | `template_sandbox` | 自由建造、资源采集、生存 | 我的世界、泰拉瑞亚 |
| **休闲 Casual** | `template_casual` | 简单操作、快速上手、碎片化 | 消消乐、2048 |
| **跑酷 Parkour** | `template_parkour` | 自动奔跑、躲避障碍、收集道具 | 神庙逃亡、地铁跑酷 |
| **塔防 Tower Defense** | `template_tower_defense` | 建造防御、波次敌人、策略 | 保卫萝卜、植物大战僵尸 |
| **卡牌 Card** | `template_card` | 卡组构建、回合制战斗 | 杀戮尖塔、炉石传说 |

### 2.2 模板结构

每个游戏模板包含以下固定结构：

```
template_roguelike/
├── template_meta.json                   # 模板元数据
├── engine/                              # 引擎层（不可修改）
│   ├── core_systems/                    # 核心系统
│   │   ├── stage_system.lua             # 关卡系统
│   │   ├── entity_system.lua            # 实体系统
│   │   ├── combat_system.lua            # 战斗系统
│   │   └── ability_system.lua           # 能力系统
│   │
│   └── base_classes/                    # 基类
│       ├── entity_base.lua
│       ├── enemy_base.lua
│       └── ability_base.lua
│
├── schema/                              # 配置 Schema（用于编辑器验证）
│   ├── game_config.schema.json
│   ├── stage.schema.json
│   ├── enemy.schema.json
│   └── ability.schema.json
│
├── default_package/                     # 默认玩法包（可作为参考）
│   ├── manifest.json
│   ├── game_config.json
│   ├── scripts/
│   ├── atlases/
│   └── audio/
│
└── docs/                                # 模板文档
    ├── getting_started.md
    ├── api_reference.md
    └── examples/
```

### 7.2 API 设计

```yaml
# 玩法包 API

# 获取玩法包列表
GET /api/v1/packages
  Query:
    - template_id: string (可选)
    - creator_id: string (可选)
    - sort: string (popular|newest|rating)
    - page: int
    - page_size: int
  Response:
    - packages: Package[]
    - total: int
    - page: int

# 获取玩法包详情
GET /api/v1/packages/{package_id}
  Response:
    - package: Package
    - download_url: string
    - launcher_key: string

# 通过 launcher_key 获取玩法包
GET /api/v1/packages/by-key/{launcher_key}
  Response:
    - package: Package
    - download_url: string

# 上传玩法包
POST /api/v1/packages
  Body:
    - manifest: Manifest
    - package_file: File
    - preview_images: File[]
  Response:
    - package_id: string
    - launcher_key: string
    - status: string

# 更新玩法包
PUT /api/v1/packages/{package_id}
  Body:
    - manifest: Manifest
    - package_file: File
  Response:
    - package_id: string
    - new_launcher_key: string
    - status: string

# 创作者 API

# 获取创作者信息
GET /api/v1/creators/{creator_id}
  Response:
    - creator: Creator
    - packages: Package[]
    - statistics: Statistics

# AI 服务 API

# 生成精灵图
POST /api/v1/ai/generate-sprite
  Body:
    - prompt: string
    - style: string
    - size: {width: int, height: int}
  Response:
    - image_url: string
    - task_id: string

# 生成动画
POST /api/v1/ai/generate-animation
  Body:
    - source_image: string
    - animation_type: string
    - frame_count: int
  Response:
    - frames: string[]
    - animation_config: AnimationConfig

# 数值平衡分析

  Body:
    - game_config: GameConfig
  Response:
    - suggestions: Suggestion[]
    - difficulty_curve: DifficultyAnalysis
```

## 十一、总结

本设计方案实现了一个完整的 **UGC 游戏平台**，核心特点：

1. ✅ **一套引擎，无限玩法** - 基于 Unity3D + Luau 的可热更新架构
2. ✅ **多模板支持** - 支持肉鸽、沙盒、休闲、跑酷等热门游戏类型
3. ✅ **AI 辅助创作** - 集成图像生成、动画生成、数值平衡等 AI 能力
4. ✅ **跨平台发布** - 支持 PC、移动端、WebGL、小程序
5. ✅ **完整生态** - 创作者工具、发布平台、玩家社区

通过 **launcher_key** 机制，实现了玩法包的唯一标识和便捷分享，让创作者可以轻松发布和推广自己的游戏玩法。
